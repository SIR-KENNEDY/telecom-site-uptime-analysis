# 📡 Telecom Site Uptime & Downtime Root Cause Analysis

![Python](https://img.shields.io/badge/Python-3.10-blue) ![Pandas](https://img.shields.io/badge/Pandas-2.0-green) ![Domain](https://img.shields.io/badge/Domain-Telecom_NOC-orange)

## Overview
Analyses 5,000+ downtime events across 100 telecom sites to compute availability KPIs, identify root causes, rank chronic underperformers, and support preventive maintenance planning.

## How to Run
```bash
pip install -r requirements.txt
python scripts/generate_data.py
python scripts/uptime_analysis.py
```

## Key Metrics
- Site availability % per month | MTTR by root cause | SLA breach detection | Pareto analysis

`Time-Series Analysis` `KPI Engineering` `Root Cause Analysis` `Pandas` `Matplotlib` `Telecom Domain`
